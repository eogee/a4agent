a4agent (CUDA 12.4 版本) — 安装后必读
=============================================

【显卡要求】
  NVIDIA 显卡 + 驱动版本 >= 551（2024 年后的 Game Ready / Studio 驱动均满足）。
  不支持 AMD / Intel 显卡 —— 请改用 Vulkan 版安装包。

【首次使用】
  1. 启动 a4agent，按向导选择模型所在目录（目录内需有 .gguf 文件）
  2. 默认推荐模型：Ornith-1.5-9B；35B 建议搭配 IQ4_XS/Q3 量化
  3. 服务默认端口 8080，可在设置中修改
  4. 启动约 90 秒后会自动裁剪内存缓存（属正常现象）

【常见问题】
  · 提示端口被占用：修改设置页端口，或关闭已占用该端口的程序
  · 启动失败/OOM：降低「上下文长度」或把 KV 缓存调为 q4_0，
    极端情况下减小 -ngl（GPU 层数）

【卸载】
  Windows 设置 -> 应用 -> 找到 "a4agent (cu12.4)" 卸载。
