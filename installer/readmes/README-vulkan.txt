a4agent (Vulkan 版本) — 安装后必读
=============================================

【显卡要求】
  通吃版：NVIDIA / AMD / Intel Arc 均可运行。
  · NVIDIA 用户：更建议用 CUDA 版安装包，性能更好
  · AMD 用户：建议 RDNA 架构 (RX 6000 及以上) + 较新的 Adrenalin 驱动
  · Intel Arc：需最新显卡驱动
  Vulkan 版体积最小、兼容面最广，但峰值性能通常低于 CUDA 版。

【首次使用】
  1. 启动 a4agent，按向导选择模型所在目录（目录内需有 .gguf 文件）
  2. 服务默认端口 8080，可在设置中修改
  3. 启动约 90 秒后会自动裁剪内存缓存（属正常现象）

【常见问题】
  · 报错找不到 Vulkan 设备：请升级显卡驱动至最新版本
  · AMD 老卡（RX 500 及更早）性能有限，建议小模型 + 小上下文

【卸载】
  Windows 设置 -> 应用 -> 找到 "a4agent (vulkan)" 卸载。
