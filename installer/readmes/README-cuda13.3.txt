a4agent (CUDA 13.3 版本) — 安装后必读
=============================================

【显卡要求】
  NVIDIA 显卡 + 支持_CUDA_13.3_的新版驱动！
  判断方法：命令行运行 nvidia-smi，右上角 "CUDA Version" 必须 >= 13.3。
  若显示 13.1 或更低，本包无法工作（会报 PTX toolchain 错误），
  请改用 CUDA 12.4 版安装包 —— 它兼容所有较新驱动。

【其他说明】
  与 CUDA 12.4 版功能完全一致，仅编译工具链更新。
  拿不准选哪个包？答案永远是：先下 cu12.4。

【首次使用】
  1. 启动 a4agent，按向导选择模型所在目录（目录内需有 .gguf 文件）
  2. 服务默认端口 8080，可在设置中修改
  3. 启动约 90 秒后会自动裁剪内存缓存（属正常现象）

【卸载】
  Windows 设置 -> 应用 -> 找到 "a4agent (cu13.3)" 卸载。
