## 0. 准备工作

### 0.1 选择测试模式

| 模式 | 说明 | 适用 |
|---|---|---|
| **A 沙箱模式（推荐）** | 用环境变量把四端 skill 根、数据目录、项目根全部指向临时目录，**所有写操作都不碰真实数据** | 全部用例 |
| **B 真实数据模式** | 直接连真实 `~/.claude` 等，只做只读检查 + 少量可恢复的写操作 | 快速冒烟 |

### 0.2 启动（模式 A · 沙箱）

PowerShell 中执行（先改 `$T` 为你想用的临时目录）：

```powershell
$T = "C:\Temp\skill-test"          # 临时根，随意
# 准备沙箱目录与假 skill
"$T\claude-skills", "$T\codex-skills\.system", "$T\dsh-skills", "$T\zcode-skills",
"$T\projects\proj-a\.claude\skills", "$T\projects\proj-a\.codex\skills",
"$T\projects\proj-b\.claude\skills" | ForEach-Object { New-Item -ItemType Directory -Force $_ | Out-Null }

function New-Skill($dir, $name, $desc) {
  New-Item -ItemType Directory -Force $dir | Out-Null
  "---
name: $name
description: ""$desc""
---

# $name
正文内容（Markdown）" | Set-Content "$dir\SKILL.md" -Encoding UTF8
}

New-Skill "$T\claude-skills\git-commit"   "git-commit"   "沙箱·提交技能"
New-Skill "$T\dsh-skills\git-dsh"         "git-commit"   "沙箱·提交技能(dsh副本)"
New-Skill "$T\zcode-skills\git-zc"        "git-commit"   "沙箱·提交技能(zcode副本)"
New-Skill "$T\codex-skills\.system\x"     "builtin-x"    "内置技能应被忽略"
New-Skill "$T\projects\proj-a\.claude\skills\deploy"   "deploy"   "沙箱·部署"
New-Skill "$T\projects\proj-a\.dsh\skills\deploy2"     "deploy"   "沙箱·部署(dsh副本)"

# 项目根列表写入沙箱数据目录
New-Item -ItemType Directory -Force "$T\data" | Out-Null
@{ roots = @("$T\projects") } | ConvertTo-Json | Set-Content "$T\data\projects.json" -Encoding UTF8

# 启动（端口如占用请更换）
$env:A4AGENT_DATA_DIR            = "$T\data"
$env:A4AGENT_CLAUDE_SKILLS_PATH  = "$T\claude-skills"
$env:A4AGENT_CODEX_SKILLS_PATH   = "$T\codex-skills"
$env:A4AGENT_DSH_SKILLS_PATH     = "$T\dsh-skills"
$env:A4AGENT_ZCODE_SKILLS_PATH   = "$T\zcode-skills"
uv run python -m uvicorn backend.app.main:app --port 18923
```

浏览器打开 **http://127.0.0.1:18923**，切到「技能管理」tab。

> 注意：`$env:` 设置只在当前 PowerShell 会话生效，重开窗口需重新设置。
> 沙箱数据库位于 `$T\data\a4agent.db`。

## 5. 回收站

### TC-15 删除 → 恢复往返
- [ ] 对任一多余副本点副本行「删除」→ 确认；卡片徽章数减少
- [ ] 「回收站」中可见条目：名称、原位置（全局/项目 · 端）、剩余天数 ≈30
- [ ] 点「恢复」→ 提示已恢复；文件回到原位置，回收站清空该项

### TC-16 恢复冲突拦截
- [ ] 删除某 skill 后，**手动在原位置新建同名目录**；再点恢复
- [ ] 应报错「原位置已存在同名目录」，且手动目录未被覆盖

### TC-17 彻底删除
- [ ] 回收站中对一条目点「彻底删除」→ 条目消失，磁盘上回收站目录同步消失

### TC-18 过期清理（30 天）
- [ ] 先制造一条回收站条目，然后停掉服务，把它的时间改成 31 天前：

```powershell
uv run python -c "
import sqlite3, pathlib, os
db = os.environ.get('A4AGENT_DATA_DIR', r'backend\database') + r'\a4agent.db'
con = sqlite3.connect(db)
con.execute(\"UPDATE skill_trash SET trash_time = datetime('now','localtime','-31 days')\")
con.commit(); print('updated:', con.total_changes)"
```

- [ ] 重启服务打开「回收站」：顶部提示「已自动清理 1 条超过 30 天的过期条目」，过期条目消失、其余保留

## 6. 迁移日志与安全

```powershell

  -Body '{"path":"C:\\Windows\\System32"}' -ContentType 'application/json'
```

## 已知边界（非 bug）

1. 只扫描主根：`<proj>/.agents/skills`、`~/.agents/skills` 次要根一期不做（ZCode 官方还认 `.agents` 兼容目录，本工具统一托管到 `.zcode` 前缀）
2. Codex 全局 `.system/` 及一切点开头目录视为系统保留，不出现在列表
3. 「同名」判定 = frontmatter `name` 相同**或**目录名相同，二者任一命中即触发冲突保护
4. 项目视图只收录至少含 1 个 skill 的项目
